# Zabbix Vision for Splunk 1.1.1

7 November 2026 · Public beta · Apache-2.0

- Enabled Splunk's built-in check for updates from Splunkbase.
- Simplified the repository documentation and retained dashboard screenshots in the user guide.
- Updated package metadata and installation links.

Install over `zabbix_vision` using the normal Splunk app upgrade process, then restart Splunk. Existing connection profiles, credentials, inputs and checkpoints are retained. Collection and dashboard behavior are unchanged from 1.1.0.
