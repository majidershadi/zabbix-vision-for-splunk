# Security reporting

Do not put credentials, private keys, session tokens, passwords.conf, splunk.secret or unredacted customer records in public issues.

For a suspected vulnerability, use [GitHub private vulnerability reporting](https://github.com/majidershadi/zabbix-vision-for-splunk/security/advisories/new) when enabled, or contact the maintainer through [the public profile](https://majidershadi.github.io/). Describe affected versions, prerequisites, impact and a minimal sanitized reproduction. Public GitHub Issues are appropriate for non-sensitive bugs and feature requests.

The current public release is 1.0.0 beta. No commercial support SLA is offered. Review security fixes before adopting an updated release.
